## 1. 要求（Why）

- 関連する要求: G-5, P-4, P-5, J-6, J-7
- 解決したい課題: 今の車の画面は、これからの予約を開始の日付ごとに並べた一覧なので、ある日のどの時間帯が埋まっていて、どこからどこまで使われているかを、行の時刻を読んで頭の中で組み立てなければならない。予約を入れるときも、日付と時刻を欄に打ち込む形で、空きを見ながら入れられない。オーナー（せいご）が spec 003 の開発環境での確認（T-30）で画面を触り、改善したほうがよいと判断した（2026-10-10 の依頼「車の予約について calendar のような表示でどこからどこまで使われているかをすぐに分かるようにして。また予約の登録操作もカレンダーのようにして」）

#### CAR-F-004 車の予約を入れられる（変更）

- **変更前との差**: 車の画面の時間割で範囲を選ぶと出る入力からも予約を入れられるようにする。「予約する」ボタンからの入力の画面は残す。予定の見え方がカレンダーになるのに合わせて AC-1・AC-9 の確かめ方と、二重登録の知らせ（AC-17）の「予定で確かめて」を「車の画面で確かめて」に変え、AC-21〜AC-29 を足す（入力の出し方（ポップアップ・シート）と範囲の選び方（ドラッグ・長押し）は「3. 変更差分」の画面に書く）
- **概要（変更）**: 家族の誰でも、車・開始日時・終了日時・行き先（任意）・メモ（任意）を入れて予約する。車の画面の時間割で使いたい範囲を選ぶと、選んだ開始と終了が入った入力が出る。「予約する」ボタンから入力の画面を開いて入れることもでき、保存の後はその予約の開始の日を選んだ車の画面に戻る。同じ車で時間が重なる予約がすでにあれば、後から入れようとした予約は止める（先に入れた予約が優先）。入れた予約は家族全員のカレンダーに出る
- **事前条件**: AUTH-F-002 でログイン済み。「使う」の車が1台以上ある（CAR-F-001）
- **正常フロー（変更）**: 車の画面で日を選び、時間割の使いたい範囲を選ぶ → 開始日時と終了日時（15分刻み）が入った入力が出る（車は「使う」の車が1台だけなら最初から選ばれている） → 車・日時を直し、行き先・メモを入れる → 「予約する」を押す → 予約が保存されて入力が閉じ、時間割に帯が出る
- **例外・バリデーション（変更）**:
  - 入力が空・欠けている: 車・開始日時・終了日時のどれかが空なら止め、その項目に「入力してください」と出す。行き先・メモは空でよい（空白だけなら空とみなす）。「使う」の車が1台も無いときは、「予約する」を押したときも時間割で範囲を選んだときも「先に車を登録してください」と出し、車の管理の画面へ進めるようにする。時間割から出た入力は、何も保存せずに閉じられ、そのときは時間割の選んだ範囲も消す。入力の外側を押しても閉じない（入れた内容が不意に消えないように）。端末の「戻る」操作は、入力を閉じるだけで車の画面に残る
  - 対象外・想定外: 次の場合は止めて理由を出す。
    - 終了日時が開始日時と同じか前（「終了は開始より後にしてください」）
    - 終了日時が今以前（「終了の日時が過ぎています」）。開始日時は今より前でもよい（乗ってから入れたとき）
    - 行き先（前後の空白を除いたもの）が50文字を超える。メモが500文字を超える
    - 同じ車で時間が重なる予約がある（「その時間は〈表示名〉の予約（〈開始〉〜〈終了〉）と重なっています」。自分の予約と重なるときも同じ）。同時に送られた2つの予約が重なるときは、先に保存された方だけが残る
    - 選んだ車が、入力している間に「使わない」になっていた（「この車は今は予約できません。選び直してください」）、または削除されていた（「この車は見つかりません。」）
    - 時間割で選ぶ範囲は、ほかの予約の帯と重なっていても、過ぎた時間でも選べる（別の車なら予約できるため。止めるかどうかは「予約する」を押したときに上の条件で決める）。帯の上から選び始めると帯を押したことになるので、帯のある時間は帯の脇の空いた所から選ぶ（選びにくければ「予約する」ボタンから入れる）。範囲は選んだ日の中で選ぶ。日をまたぐ予約は、入力で終了の日付を直して入れる
  - 処理に失敗: 「書き込みに失敗したとき」の知らせを出し、入力を残す（時間割から出た入力は閉じない）。「予約する」を続けて2回押しても、予約されるのは1件だけ。通信できないと出た後に入力を直して押し直したとき、最初の予約がすでに保存されていたら、止めて「この予約はすでに登録されています。車の画面で確かめて、必要なら直してください。」と出す

#### CAR-F-005 予約をカレンダーで見られる（変更）

- **変更前との差**: 名前を「これからの予約と使用中の予約を見られる」から変える。開始の日付ごとの一覧をやめ、月のカレンダーと、選んだ日の時間割（0〜24時、予約を帯で）にする。これからの予約だけでなく、過去の日の予約（終わった予約）も見られる。帯は車ごとの色で塗る。AC-1〜AC-5 の確かめ方（AC-3 は日をまたぐ予約の印も）と AC-7 の言い方（「予定の API」→「予約を引く API」）を変え、AC-9〜AC-15 を足す
- **概要（変更）**: 家族の誰でも、すべての車の予約を、月のカレンダーと、選んだ日の時間割で見られる。月のカレンダーでは、予約が一部でもかかる日に印を出す（終了がちょうど 0:00 の日には出さない）。日を選ぶと、その日の時間割（0〜24時）に予約を帯で出す。帯は開始から終了までの位置と長さで出し、車ごとの色で塗り、車の名前・予約した家族の表示名・時間・行き先を出す。使用中の予約の帯には「使用中」と出す。先の日も過去の日も見られる。帯を押すと、その予約の中身（メモを含む）が出る
- **事前条件**: AUTH-F-002 でログイン済み
- **正常フロー（変更）**: アプリのホームで「車」を押す → 今月のカレンダーと、今日の時間割が出る → 日を選ぶ（前の月・次の月へも移れる） → その日の時間割に予約が帯で出る → 帯を押すと、その予約の中身（メモを含む）が出る
- **例外・バリデーション（変更）**:
  - 入力が空・欠けている: 選んだ日に予約が無いときは、時間割に帯を出さない（知らせは出さない）。車が1台も無いときは「車が登録されていません」と出し、車の管理の画面へ進めるようにする
  - 対象外・想定外: 取り消した予約は出ない（消えているため）。「使わない」の車の予約も出し、帯を「使わない」の車と分かる形で出し、車の名前に「使わない」と添える。日をまたぐ予約は、またいだ日それぞれの時間割に、その日にかかる分の帯を出し、帯の時間は全体を出す（「22:00〜10月11日(日) 2:00」）。別の車の予約が同じ時間にあるときは、どちらの帯も隠れずに出す。予約の中身から車の画面へ戻ったとき、予約を直した後・取り消した後に車の画面へ戻ったときは、その予約の開始の日（直した後は直した後の開始の日）を選んだ状態で出す。前の月・次の月へ移ったときは、その月の1日（今月へ戻ったときは今日）を選んだ状態にする
  - 処理に失敗: 「読み込みに失敗したとき」の知らせを出す。前の月・次の月へ移ったときに読み込めなかったときも同じ知らせを出す
- **受入基準（変更）**:
  - AC-1: Given 日本時間 2026-10-07 20:00、「ノア」の予約が せいご 10月7日 8:00〜10:00、くうご 10月7日 19:00〜22:00、母 10月8日 9:00〜10:00 / When 父が車の画面を開く / Then 2026年10月のカレンダーで7日と8日に印が出て、10月7日の時間割に、せいごの帯（8:00〜10:00）と、くうごの帯（19:00〜22:00、「使用中」付き）が出る

#### CAR-F-006 自分の予約を直せる（変更）

- **変更前との差**: 車の画面がカレンダーになり終わった予約も帯で出るのに合わせて、正常フローと、使用中の予約を早く返したときの扱い、AC-1・2・7・8・21 の確かめ方を「予定に出る」から「時間割に帯で出る」へ変える
- **概要**: 予約した本人が、まだ始まっていない予約の車・開始日時・終了日時・行き先・メモを直せる。使用中の予約は、終了日時・行き先・メモだけを直せる（延ばすとき、早く返したとき）。終わった予約は直せない
