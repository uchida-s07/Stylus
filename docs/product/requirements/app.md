## 機能要件

### APP-F-001 端末のホーム画面に追加して、アプリとして開ける

- **概要**: Android の Chrome でアプリを端末のホーム画面に追加（インストール）でき、そのアイコンから開くと、アドレスバーの無い画面でアプリが開く。追加しなくても、スマホ・PC のブラウザでそのまま使える
- **事前条件**: 本番（またはプレビュー）の URL を Chrome で開ける
- **正常フロー**: Chrome でアプリを開く → メニューの「ホーム画面に追加」（「アプリをインストール」）を選ぶ → 端末のホーム画面に「Stylus」のアイコンができる → アイコンをタップする → アドレスバーの無い画面でアプリが開く（ログイン済みならアプリのホーム）
- **例外・バリデーション**:
  - 入力が空・欠けている: 該当なし（利用者が入力するものが無い）
  - 対象外・想定外: 端末のホーム画面への追加に対応していないブラウザでは追加できないが、ブラウザのまま使える。新しい版を公開した後に古い版が端末に残っているときは、新しい版に切り替える
  - 処理に失敗: 通信できないときにアイコンから開いたら、真っ白な画面にせず、端末に保存済みの画面を出して「通信できません。電波の良いところでもう一度開いてください。」と出す
- **受入基準**:
  - AC-1: Given 本番用にビルドしたフロント / When 出力された Web アプリマニフェストを読む / Then 名前が「Stylus」、表示モードが standalone（アドレスバーなし）、`start_url` がアプリのホーム、192px と 512px のアイコンが入っている（出典: specs/001）
  - AC-2: Given 本番用にビルドしたフロント / When 出力されたファイルを調べる / Then Service Worker があり、アプリの画面（HTML・JS・CSS）を端末に保存する対象にしている（出典: specs/001）
  - AC-3: 〔例外：処理に失敗〕Given この端末でログイン済みでアクセストークンは期限内、画面は読み込めたが通信できない（API・Supabase への要求がネットワークエラーになる） / When アプリを開く / Then 「通信できません。電波の良いところでもう一度開いてください。」と表示される（出典: specs/001）
- **対応する要求**: J-1
- **出典**: specs/001
