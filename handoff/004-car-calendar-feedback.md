# spec 004 車の予約のカレンダー：T-13 の確認で出た直し（引き継ぎ）

一時資料。決めたことを spec 004 へ移し終えたら消す（spec 004 の /spec-close で `handoff/003-car-calendar.md` と一緒に消す）。

## 1. オーナーの指摘（2026-10-16、Pages のプレビューで確認）

動き（予約・重なりで止まる・中身・直す・取り消す）に問題は無い。デザインと表示について次の3点を直す。

1. **画面の組み立て**：Google カレンダーのように、まず月のカレンダーを出し、日をタップするとその日の具体的な予定（時間割）が見られる形にする。操作方法は Google カレンダーをまねる
   - 今は1つの画面に、上に月のカレンダー、下に選んだ日の時間割を並べている（月のセルが縦に長く、スマホでは時間割まで遠い）
2. **月のカレンダーの印**：同じ日に2台の車の予約を入れても、月のカレンダーには印が1つしか出ない
   - 原因：`CarCalendar.tsx` の `reservedDays()` が「予約のある日」の集合しか持たず、日ごとに点を1つだけ描いている（車も色も見ていない）
3. **範囲の選び方**：長押ししてから引く操作は使いにくい。自作に変えてよいので、Google カレンダーのように、その日の時間割をタップすると枠が出て、枠を動かして時間を選べるようにする
   - 2026-10-10 の D-4 で最初に選んだ「タップ→仮の帯→端を引く」が、FullCalendar では標準で無いため取り下げていたもの（handoff/003-car-calendar.md）。自作なら実現できる

## 2. 決めること（次の作業の最初にオーナーに確認する）

推奨は★。

- **F-1 画面の分け方**
  - ★A：`/car` は月のカレンダーだけにする。日をタップすると、その日の時間割の画面（全画面）へ移る。時間割の画面には「月へ戻る」と前の日・次の日がある。URL は月を `/car?month=YYYY-MM`、日を `/car?date=YYYY-MM-DD` のように分ける（今の `?date=` への戻り先（AC-12・14・15・26、F-007/AC-1・8）は、そのまま日の画面へ戻る意味になる）
  - B：1つの画面のまま、日をタップすると月のカレンダーを畳んで時間割を広げる
- **F-2 月のカレンダーのセルの中身**
  - ★A：予約ごとに、車の色の短い帯（チップ）に車の名前を出す（Google カレンダーの月の表示と同じ）。入りきらない分は「他 n 件」
  - B：車ごとに、車の色の点を並べる（同じ車の予約が2件でも点は1つ）
- **F-3 時間割の部品**
  - ★A：月のカレンダーも時間割も自作にし、FullCalendar を外す（どちらも作りは単純で、外すと車の画面の塊が約 77 kB（gzip）軽くなり、日のセルが読み上げから外れる問題（T-6）も無くなる。FullCalendar を使う ADR は書かず、自作にした理由の ADR を書く）
  - B：時間割だけ自作にし、月のカレンダーは FullCalendar のまま
- **F-4 枠の操作**（Google カレンダーのアプリに合わせた案）
  - ★時間割の空いた所をタップ（クリック）すると、そこから1時間の枠が出る（15分刻みにそろえる）。枠の上下の端のつまみを引くと開始・終了が変わり、枠の中を引くと枠ごと動く。枠をもう一度タップする（または枠の「予約する」）と、今の入力（ポップアップ・シート）が開始・終了の入った形で出る。枠の外の空いた所をタップすると枠が消える（または移る）
  - 決めること：最初の長さ（★1時間）、PC でも同じ操作にするか（★同じ。PC はドラッグで範囲を作る操作も足すかを決める）、枠から入力を出すきっかけ（★枠をタップ）
- **F-5 日の画面の移り方**：前の日・次の日をボタンにするか、左右のスワイプも足すか（★ボタン＋スワイプ。ただしスワイプは枠を動かす操作とぶつからないように、枠の外だけで受ける）

### 決まったこと（2026-10-16 オーナー決定）

- F-1：A（`/car` は月のカレンダーだけ、日をタップすると全画面の時間割）
- F-2：A（予約ごとに車の色の短い帯に車の名前、入りきらない分は「他 n 件」）
- F-3：A（月も時間割も自作にし、FullCalendar を外す）
- F-4：推奨の形（空いた所のタップで1時間の枠、端で伸び縮み・中で移動、枠のタップで入力。PC も同じ）
- F-5：推奨の形（前の日・次の日はボタン＋左右のスワイプ。スワイプは枠の外だけ）
